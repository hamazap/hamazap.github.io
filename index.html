🤔 What is laya-server?

laya-server is a friendly, self-hosted program that lets you run decision models on your own computer. Think of it as a smart helper that organizes your options and shows you the best path forward.

It comes with two main parts:

  • A web interface - a simple, visual screen you interact with using your browser
  • An API - a behind-the-scenes tool that lets other programs talk to your decision models

It's compatible with the TypeSafe Jev API format, meaning it works smoothly with other Jev-based tools and AI systems.
